# Oliyam

**Light, reimagined.**

Oliyam is an open-source desktop photographic editor from Absolute Markup, inspired by the straightforward creative workflow of Snapseed and built on the Rust-based [LightCraft](https://github.com/storytold/lightcraft) imaging engine.

## Product direction

- Native desktop, Linux first, followed by Windows and macOS.
- Lightweight filesystem browser; a photograph can be opened directly.
- An Adwaita-inspired workspace for Looks, Tools and editable Stacks.
- Non-destructive editing, classical selective adjustments and healing.
- Extensive analogue photographic and motion-picture film simulations, with profile provenance and independently documented asset licences.
- Local, offline-first processing; no AI features, subscriptions, accounts or advertisements.

## Development status

Oliyam is in pre-alpha development. This repository is a full fork of LightCraft. The inherited desktop application, interface, catalogue, internal crate names and packaging are transitional. The features above are product goals, not a claim of implementation or release readiness. Do not install or distribute upstream-branded builds as Oliyam.

See [Phase 01 application independence](docs/oliyam/phase-01.md) for the baseline and release gates.
